Database Constraints, Triggers & Security Hardening

Layer Rule / Mechanism Protection Provided
SQL Constraints ON DELETE RESTRICT, UNIQUE(email), CHECK Prevents deleting books/members with loan history, blocks duplicate emails, ensures copies ≥ 0 and due_date ≥ borrow_date.
SQL Triggers trg_loans_after_insert / after_return Automatically decrements available_copies on borrow (blocking if 0) and increments on return inside an atomic transaction.
Express API Prepared Statements + Whitelist Sort Zero SQL injection across filters and ORDER BY clauses, Helmet CSP headers, 50kb payload cap, and rate limiting.
